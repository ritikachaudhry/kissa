# Kissa — website

Branch: `dev`

- `index.dc.html` — home page, drop grid, product page (open directly in a browser; loads `support.js`)
- `assets/` — logos, textures, Maku font, drop imagery
- `index.html` (in /export of the design project) — single-file offline bundle

## Commit to a new dev branch
```
git clone git@github.com:ritikachaudhry/kissa.git
cd kissa
git checkout -b dev
# copy the contents of this folder into the repo root
git add .
git commit -m "Kissa site: home, drop grid, product page"
git push -u origin dev
```
